# Sistema de Gestión - Papelería ✏️📊

Aplicación de escritorio moderna desarrollada en Python para la administración integral de una papelería. Permite controlar el inventario de forma visual, realizar ventas mediante un Punto de Venta (POS) dinámico, consultar métricas clave en tiempo real y generar reportes ejecutivos en PDF.

---

## 🛠️ Tecnologías y Librerías
* **Python 3:** Lenguaje principal de desarrollo.
* **CustomTkinter:** Framework para una interfaz gráfica moderna, elegante y adaptada a modo oscuro.
* **SQLite:** Base de datos local ligera y eficiente.
* **ReportLab:** Librería para la estructuración y exportación de reportes en PDF.

---

## 🚀 Guía de Instalación y Configuración (Windows)

### 1. Requisitos Previos
Asegúrate de tener instalado **Python** (versión 3.10 o superior) en tu equipo. Al instalarlo, recuerda marcar la casilla **"Add Python to PATH"**.

### 2. Descargar o Clonar el Proyecto
Descarga el código fuente en tu computadora en una carpeta de tu preferencia ejecutando
